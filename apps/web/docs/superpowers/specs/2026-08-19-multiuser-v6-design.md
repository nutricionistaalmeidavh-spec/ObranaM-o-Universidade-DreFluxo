# FluxoDRE Campo v6 Multiusuário — Design

Objetivo: autenticação e três perfis (Admin, Encarregado, Funcionário), dados centrais por empresa/obra, autorização no backend e migração do IndexedDB atual. Usuário autenticado sem vínculo pode criar sua própria empresa/obra e vira Admin daquele tenant. Admin vê/modifica tudo; Encarregado vê tarefas/frentes e registra presença/falta; Funcionário recebe somente suas próprias atribuições de hoje e dos próximos 7 dias. A migração local não apaga o snapshot do aparelho. Estrutura preparada para Empresa → Obras → Membros → Funcionários → Planejamentos/Frentes → Apontamentos. Backend usa AppDeploy Auth + Database, com membership por email/userId e projectId/companyId em todos os registros. Funcionário nunca recebe o snapshot completo da obra.
