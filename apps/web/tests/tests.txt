# Tests

## Test 1 - Configurar Gemini uma vez e usar o chat [sanity]
Viewport: desktop (1280x800)
Covers: GET /api/finance/gemini/status, POST /api/finance/gemini/save, persistência backend por empresa, POST /api/finance/chat, Gemini 3.7 Flash
Description: Confirma que a API Key é informada uma única vez e reutilizada automaticamente nas sessões seguintes.

Steps:
1. Abrir Financeiro sem Gemini configurado e informar uma API Key válida
2. Salvar e abrir Pergunte ao Financeiro
3. Recarregar a página e abrir Pergunte ao Financeiro novamente

Expected: O Gemini continua configurado após recarregar; não existe campo de senha/desbloqueio e o chat funciona sem pedir novamente a API Key.

## Test 18 - IA MH cruza motores determinísticos sem alterar dados
Viewport: desktop (1280x800)
Covers: POST /api/desktop/ai/analyze, device token, Gemini compartilhada, produção, planejamento, RH, financeiro, custos, medições, documentos, ranking executivo e modo somente leitura
Description: Confirma que a IA MH recebe apenas fatos calculados pelos motores Desktop, interpreta o ranking executivo e não executa ações.

Steps:
1. No Desktop vinculado, abrir IA MH após existir histórico operacional, custos, medições e documentos
2. Perguntar qual obra merece mais atenção hoje e solicitar os motivos
3. Conferir a resposta e retornar às telas de origem

Expected: A resposta usa métricas dos motores determinísticos e o ranking recebido, diferencia fatos de hipótese/recomendação, informa dados ausentes quando necessário e nenhum dado operacional, financeiro, documental, de medição ou RH é alterado.
